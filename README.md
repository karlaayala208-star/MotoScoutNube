# MotoScoutNube - App Android (Client)

Aplicación nativa diseñada para brindar asistencia técnica y seguridad en tiempo real a motociclistas, integrando servicios de geolocalización, monitoreo y servicios de mecanica en tiempo real.

## 🚀 Funcionalidades Principales
- **Rastreo en Tiempo Real:** Integración con **Google Maps API** para la ubicación de servicios mecánicos y calificación de proveedores.
- **Alertas Preventivas:** Sistema de monitoreo de sensores para el control de kilometraje y recordatorios de mantenimiento.
- **Botón de Pánico:** Implementación de protocolos de seguridad críticos mediante el envío de alertas vía SMS en caso de emergencia.
- **Gestión de Usuarios:** Autenticación y consumo de datos mediante APIs JSON conectadas al servidor central.

## 🛠️ Tecnologías Utilizadas
- **Lenguaje:** Java
- **Entorno:** Android Studio
- **APIs:** Google Maps SDK, JSON
- **Control de Versiones:** Git
